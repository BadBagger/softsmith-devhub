WASTEBOND — Tame. Fight. Survive.

A post-apocalyptic creature-taming browser RPG rendered on an HTML canvas. Move with arrow keys, WASD, or the on-screen D-pad; battle with Attack, Capture, or Flee. This game requires JavaScript and is not screen-reader navigable beyond this description.
